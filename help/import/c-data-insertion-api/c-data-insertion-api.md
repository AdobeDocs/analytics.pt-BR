# API de inserção de dados

A [API de Inserção de Dados](https://developer.adobe.com/analytics-collection-apis/methods/data-insertion/) e a [API de Inserção de Dados em Massa](https://developer.adobe.com/analytics-collection-apis/methods/bulk-data-insertion/) são métodos usados para enviar dados de coleção do lado do servidor para o Adobe Analytics. As chamadas da API de inserção de dados aceitam um evento por vez. A API de inserção de dados em massa aceita arquivos formatados CSV contendo dados do evento, um evento por linha.

Se você estiver trabalhando em uma nova implementação da coleção do lado do servidor, a Adobe recomenda usar a API de inserção de dados em massa.

Para endpoints, formatos de solicitação e resposta e a referência completa da variável, consulte a documentação da [API de Inserção de Dados](https://developer.adobe.com/analytics-collection-apis/methods/data-insertion/) e da [API de Inserção de Dados em Massa](https://developer.adobe.com/analytics-collection-apis/methods/bulk-data-insertion/) no Adobe Developer.
